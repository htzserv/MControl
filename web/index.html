Remove / Unpair Server

Server
PEER
🔗
Unpair & Keep Tunnels (Recommended) Removes this panel's Peer key from the server and deletes it from this panel, while keeping all active tunnels running uninterrupted.
🔓
Unpair Only (Keep Server in Panel) Disconnects Peer Agent and switches the server back to SSH mode in this panel. Tunnels stay untouched.
🗂️
Remove from Panel Only Deletes the record from this panel's database without connecting to the server (best for offline/dead nodes).
🧨
Full Uninstall (Agent + All Tunnels) Permanently stops and removes MControl Peer Agent, all mcontrol-tun-* tunnels & iptables rules on the server, and deletes it from the panel.
