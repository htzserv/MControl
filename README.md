# MControl Android (MDesign)

Native Android client for **MControl** built with Kotlin, Jetpack Compose, Material 3 (MDesign), OkHttp, Biometric Lock, and WorkManager background outage alerts.

## Automatic APK Build (No Android Studio Needed)
Push this repository to GitHub (`main` branch) and GitHub Actions (`.github/workflows/android-apk.yml`) will automatically compile and publish **`MControl-Android-v1.0.0.apk`** under **Releases**.
